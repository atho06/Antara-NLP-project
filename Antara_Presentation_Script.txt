Slide 2 — The Mental Health Gap ⏱ ~40 seconds
==================================================

[Click. Cards animate in one by one.]

"Let's start with the problem.

India has one of the highest burdens of mental illness in the world — around 200 million people affected. ⏸
Yet there's only one psychiatrist for every 100,000 people.

The barriers are real — therapy is expensive, stigma stops people from asking for help, and rural areas have almost no access at all. ⏸

Even digital tools fail here. Static questionnaires and rigid forms miss emotional context — they can't tell if someone is actually fine or just saying they are.

Antara is designed to fill this gap."

Slide 3 — What is Antara? ⏱ ~45 seconds
==================================================

[Click. Pillars float in.]

"So what is Antara exactly?

Antara is a self-help emotional wellness companion. Users chat with Lia, our empathetic AI, to process their feelings, do guided reflections, and practice wellness activities. ⏸

There are four core pillars:

Lia — the conversational AI, powered by a local language model.
An NLP pipeline — five different analyzers running on every single user response in real-time.
An Emergency Safety Net — if the app detects serious distress, it automatically sends an SMS to the user's trusted contact.
And privacy-first design — everything runs locally. No data ever leaves the user's device."

Slide 4 — System Architecture ⏱ ~35 seconds
==================================================

[Click. Architecture boxes appear.]

"Here's the full system architecture.

The user interacts through a Streamlit web interface. ⏸
That connects to three things in parallel: Lia, the crisis detector, and the adaptive question flow engine.

All three feed into the NLP Analysis Pipeline — five independent Python modules running simultaneously. ⏸

If the crisis detector fires at high severity, emergency_service.py dispatches an SMS. All session data is stored in SQLite locally, and Lia's LLM runs on Ollama — completely on-device, no internet needed."

==================================================
Slide 5 — Lia: The Conversational AI Engine ⏱ ~55 seconds
==================================================

[Click. Table rows fade in.]

"Let's talk about Lia — the heart of Antara.

Lia is powered by llama3.2:3b, running locally via Ollama. No API key. No internet. No data ever sent to any cloud service. ⏸

The NLP techniques we use here:

Contextual language generation — the transformer model generates responses based on the entire conversation history.

Prompt engineering — we crafted a system prompt that keeps Lia in a therapeutic, non-directive tone at all times. ⏸

Multi-turn memory — the full conversation history is passed on every single call, so Lia always has context.

Two key functions — generate_followup() creates an empathetic follow-up question, and generate_followup_acknowledgement() validates the user's feeling before probing deeper.

And if Ollama isn't running? Lia falls back to a built-in acknowledgment library — the app never breaks."

==================================================
Slide 6 — Crisis Detection System ⏱ ~50 seconds
==================================================

[Click. Flow diagram appears, then category cards.]

"This is probably the most important NLP component — the crisis detection system.

If a user expresses self-harm or suicidal ideation, the app must respond immediately. ⏸

We built a 50+ pattern regex engine across four categories:
- Self-harm patterns — things like 'want to hurt myself', 'cut myself'
- Suicide ideation — 'want to die', 'end my life', 'suicidal'
- Threats to others — 'want to kill someone'
- Immediate danger — 'I am not safe', 'I cannot go on'

The key NLP challenge here is negation handling. ⏸ We use a 60-character look-behind window. So the sentence 'I don't want to die' correctly evaluates as safe, while 'I want to die' triggers the crisis response.

This is essential — without negation handling, we'd have too many false positives that could make the app feel alarming and untrustworthy."

Slide 7 — Adaptive Conversation Flow ⏱ ~40 seconds
==================================================

[Click. Flow steps appear, then theme table.]

"The last component I'll cover is the adaptive question flow.

Antara doesn't use a fixed questionnaire. ⏸ The conversation branches dynamically based on the NLP-detected emotional theme of the user's responses.

We support six emotional themes:
Anxiety, Sadness and Grief, Burnout, Relationship issues, Loneliness, and Physical or somatic concerns.

Each theme maps to its own set of tailored questions. So someone who's anxious gets asked about their worry triggers and coping mechanisms — not the same questions as someone who's grieving. ⏸

The session also starts by detecting the user's time preference — from a quick 5-minute check-in to a fully open-ended conversation. This adaptive branching is what makes Antara feel like a conversation, not a form.

I'll now hand over to my teammate Athira, who will walk you through the NLP analysis pipeline and the remaining features."

Slide 8 — The Multi-Layer NLP Analysis Pipeline ⏱ ~60 seconds
==================================================

[Click. Analyzer cards float in one by one.]

"Thank you Ruthvika. Hi everyone, I'm Athira.

While Ruthvika covered how Antara talks to users, I'll walk you through how it understands them — through five NLP analyzers running in the background on every response. ⏸

First — the Hedging Detector. This catches epistemic minimizing language: phrases like 'I guess', 'just a bit', 'probably nothing', 'I don't want to be a burden.' These are signals of emotional suppression — the user is downplaying their distress. We detect four categories: minimizers, epistemic modals, diminutives, and self-doubt patterns. ⏸

Second — the Emotion Trajectory Analyzer. This is a lexicon-based classifier across five emotion dimensions: anxiety and fear, sadness and despair, overwhelm and burnout, guilt and shame, and anger. It tracks the emotional arc across the entire session — are they getting better or worse? ⏸

Third — the Theme Extractor. It clusters keywords into four clinical life domains: Work and Performance, Interpersonal Isolation, Somatic Dysregulation, and Perfectionism. This directly feeds the adaptive question flow Ruthvika described. ⏸

Fourth — the Inconsistency Detector. This flags contradiction patterns — things like 'I'm totally fine, but I cry every morning.' That gap between what someone says and what they describe is a classic emotional masking signal. ⏸

And fifth — the Edit Analyzer. This one is unique. It uses Python's SequenceMatcher to compare the original and edited version of a user's message — detecting when someone types something emotionally significant and then deletes it before sending. That self-censorship is itself meaningful data."

==================================================
Slide 9 — Emergency Contact SMS System ⏱ ~35 seconds
==================================================

[Click. Flow and SMS box appear.]

"When the crisis detector fires at high severity, the Emergency Service activates.

It retrieves the user's pre-registered trusted contact, composes a compassionate SMS, dispatches it via Twilio or Fast2SMS, and logs the full alert to SQLite. ⏸

The message is simple — it doesn't share any conversation content, just a brief notice to reach out. Privacy is protected at every step.

If no SMS credentials are configured — say, in a demo environment — the system logs a simulated dispatch so the app never fails or crashes.

And critically: the user registered their emergency contact voluntarily during sign-up. It's fully consent-based."

Slide 10 — User Experience Walkthrough ⏱ ~25 seconds
==================================================

[Click. Steps appear.]

"The user journey through Antara is straightforward.

Register with an emergency contact. Choose a conversation mode. Do a quick emotional check-in using 8 quick-response chip options. Chat with Lia through adaptive questions. If the crisis path triggers, the safety UI appears and the SMS is sent. And optionally, do wellness activities — breathing exercises, grounding techniques, journaling. ⏸

The sidebar also has a theme toggle — Light mode, Dark mode, or System mode — because a calming visual environment matters during sensitive conversations."

---

==================================================
Slide 11 — Privacy-First Architecture ⏱ ~20 seconds
==================================================

[Click.]

"Privacy is a core design principle, not an afterthought.

The LLM runs entirely on-device via Ollama — zero data sent to OpenAI or any cloud. Session data lives in SQLite on the user's machine. No telemetry. Passwords are hashed. The edit analyzer detects patterns but never stores raw text. ⏸

This is an academic prototype — production deployment would require encryption at rest, audit logs, and regulatory compliance."

[Click.]

"Quick overview of the stack:

Streamlit for the web UI — rapid prototyping for ML and NLP apps.
Ollama with llama3.2:3b for local language model inference.
Python for all five NLP modules.
SQLite for all storage — zero config, runs anywhere.
FastAPI as the backend REST API.
Twilio or Fast2SMS for emergency SMS.
And CSS injected via Streamlit for the Light, Dark, and System themes."

==================================================

"To summarize where NLP is active across the system:

At the input layer — tokenization, regex normalization, skip-phrase detection.
At the semantic layer — theme clustering, valence scoring, hedging patterns, contradiction detection, and edit delta analysis.
At the generation layer — transformer LLM with multi-turn dialogue and prompt engineering.
And at the safety layer — 50+ crisis regex patterns with negation look-behind and severity routing that triggers the emergency SMS.

Antara is a complete, multi-signal NLP pipeline — not just a chatbot."
